# Orbit — calm life OS

A calm, visual life planner: daily journal (3 priorities, habits, reflections), time-blocked week planning, life wheel, money jars, idea garden, and a ChatGPT "thinking layer" via a structured sync file.

- Static site: `index.html` (no build step)
- Data is stored in the browser (localStorage). Use **Settings › Download backup** regularly.
- Deploys on Vercel as a static project.
